# Weather Journal

A weather journal — enter a zip code and how you're feeling, and the app records it alongside the current conditions.

## Stack

Node · Express · OpenWeatherMap API · vanilla JavaScript

## Features

- Fetches current weather for a given zip code
- Stores date, temperature and a personal note
- Updates the page with the most recent entry, asynchronously

## Running it

```bash
npm install
node server.js
```

Add your OpenWeatherMap API key in `website/app.js`. The server runs on port 3000.
